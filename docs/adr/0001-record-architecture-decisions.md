# 0001. Record architecture decisions

- Status: Accepted
- Date: 2026-10-13

## Context

People and AI agents work on this project. Agents do not remember earlier sessions.
They must find the reasons for decisions in the repository.

## Decision

We record each important decision in an ADR in `docs/adr/`.

## Consequences

- Agents and new contributors can find the reasons for decisions.
- Each important decision needs a short document.
