# STE allowlist

The files in this list are exempt from Simplified Technical English (STE).
Write these files in standard English.

| File | Reason |
|------|--------|
| `README.md` | The first page for visitors. It uses standard English to introduce the project. |
| `LICENSE` | Third-party legal text (Apache License 2.0). Do not change it. |

## Procedure to change the allowlist

1. Open an issue. Give the reason for the change.
2. Change the table in this file.
3. Change the allowlist section in `.vale.ini`. The two lists must be the same.
4. Get approval from a maintainer in the pull request.
