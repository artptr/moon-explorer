Reports an entry of workspace.inheritedTasks in moon.yml with a global task ID that no inherited file of the project contains. The entry has no effect. Possible causes: the ID has a typing error, or the files in .moon/tasks/ that apply to the project do not contain the task.

The inspection examines the items of include and exclude, and the keys of rename. It uses the data of the last load of the tasks. If the plugin has no data, the inspection does not report problems.

The quick fix removes the entry. If the entry is the last item of include, the list becomes empty. Thus the project continues to inherit no tasks.

Example:

workspace:
  inheritedTasks:
    exclude: ['lnt']
